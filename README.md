# Laboratorio VR — Manipulación y ensamblaje 3D

**Práctica 3.1 | Desarrollo de soluciones en ambientes virtuales**

Aplicación web de realidad virtual desarrollada con Three.js y WebXR, orientada a la manipulación y al ensamblaje de objetos tridimensionales mediante seguimiento de manos.

## Objetivo

Desarrollar un entorno inmersivo en el que el usuario pueda seleccionar, mover y colocar cinco piezas geométricas en sus destinos correspondientes, utilizando Meta Quest 3.

## Características

- Escenario tridimensional con mesa de trabajo.
- Cinco piezas geométricas con destinos específicos.
- Seguimiento de ambas manos mediante WebXR.
- Selección y movimiento de piezas con gestos de pinza.
- Validación de colocación y ajuste a destinos.
- Contador de progreso de 0/5 a 5/5.
- Cronómetro de la actividad.
- Señales visuales y sonidos de retroalimentación.
- Función de reinicio del laboratorio.
- Portada responsiva desarrollada con Bootstrap 5.

## Tecnologías

- HTML5
- CSS3
- JavaScript ES Modules
- Bootstrap 5
- Three.js
- WebXR

## Requisitos

- Navegador compatible con WebXR.
- Meta Quest 3 para utilizar el modo de realidad virtual.
- Conexión a Internet para cargar las bibliotecas desde CDN.
- Seguimiento de manos habilitado en el dispositivo.

## Instrucciones de uso

1. Abrir la aplicación desde su URL.
2. Seleccionar **Explorar laboratorio**.
3. Activar el modo de realidad virtual.
4. Acercar una mano a una pieza geométrica.
5. Realizar el gesto de pinza para sujetarla.
6. Mover la pieza hasta su destino correspondiente.
7. Soltarla y completar el ensamblaje de las cinco piezas.
8. Utilizar **Reiniciar** para comenzar nuevamente.

## Ejecución local

Abrir el proyecto en Visual Studio Code y ejecutar
`index.html` mediante Live Server.
